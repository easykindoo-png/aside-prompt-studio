# Aside Prompt Studio (나만의 AI 프롬프트 라이브러리)

`https://dexa.art/aside/`의 감각적인 인터페이스와 안전성 원칙을 참고하여, 사용자가 직접 프롬프트를 등록·수정·활용할 수 있도록 제작된 **모던 웹 프롬프트 라이브러리**입니다.

---

## 🌟 주요 차별화 기능 및 특징

1. **실시간 변수 입력기 (Interactive Variable Customizer)**
   - 프롬프트 내 `{{변수명}}` 형태의 플레이스홀더를 자동 분석하여 입력 폼을 제공합니다.
   - 값을 입력하면 실시간으로 완성된 프롬프트가 동적으로 조합되어 즉시 복사할 수 있습니다.
   - `💡 예시값 채우기` 버튼으로 한 번에 기본 예시 데이터를 테스트해 볼 수 있습니다.

2. **나만의 프롬프트 등록 및 관리 (CRUD & LocalStorage)**
   - `+ 프롬프트 추가` 버튼으로 웹 화면에서 새로운 프롬프트를 즉시 등록하고 편집·삭제할 수 있습니다.
   - 브라우저 로컬 저장소(LocalStorage)에 영구 보관되어 새로고침 후에도 유지됩니다.

3. **안전 중단 수칙 (Safe Stop Rule)**
   - 브라우저 제어 AI 에이전트(Aside, Claude Code 등)가 임의로 결제, 최종 발송, 영구 삭제 등의 위험한 행동을 하지 않도록 **어느 지점에서 멈춰야 하는지(Safe Stop)**를 카드와 상세 모달에 명시합니다.

4. **다양한 원클릭 복사 옵션**
   - **📋 프롬프트 복사**: ChatGPT, Claude, Gemini 등에 바로 붙여넣기 가능한 완성형 텍스트 복사.
   - **⚡ CLI 명령어 복사**: Aside CLI 터미널에서 즉시 실행할 수 있는 `aside "..."` 형태 복사.

5. **데이터 백업 및 복원 (JSON Import & Export)**
   - 언제든지 작성한 프롬프트들을 JSON 파일로 내보내어 백업하거나 다른 PC/동료에게 전달할 수 있습니다.

6. **검색 & 카테고리 필터**
   - 제목, 설명, 태그, 사이트(예: coupang, hometax, naver) 실시간 검색 지원
   - 카테고리별 칩 필터 및 ⭐ 즐겨찾기 보관함 제공

7. **모던 다크 / 라이트 테마 지원**
   - 오른쪽 상단 토글 버튼을 통해 다크 모드와 라이트 모드를 자유롭게 전환할 수 있습니다.

---

## 🚀 실행 방법

### 방법 1 (가장 간단한 방법)
- 프로젝트 폴더 내 **`start.bat`** 파일을 더블클릭하거나, **`index.html`** 파일을 더블클릭하여 브라우저에서 엽니다.

### 방법 2 (로컬 웹서버 실행)
터미널에서 아래 명령어를 실행 후 브라우저로 접속합니다:
```bash
python -m http.server 8080
# 접속 주소: http://localhost:8080
```

## 📁 파일 구성
- `index.html`: 웹 애플리케이션 구조 및 모달 팝업
- `styles.css`: 모던 반응형 스타일시트 (다크/라이트 모드 대응)
- `app.js`: 변수 파싱, 로컬 스토리지, 복사, 모달 등 핵심 인터랙션 로직
- `prompts-data.js`: 실무에서 바로 쓸 수 있는 12개 이상의 검증된 기본 프롬프트 세트
- `start.bat`: 원클릭 실행 배치 파일
